常见问题

需要付费吗？
App 本身免费。AI 功能使用你自己在 OpenAI、Anthropic、Google、DeepSeek、OpenRouter 等服务商申请的 API Key，费用由服务商按用量收取。

手写作答用不了？
手写作答和图片题需要支持图片输入的模型（例如 Claude、GPT、Gemini、通义千问 VL）。纯文字模型无法识别图片。

提示 HTTP 401 / 403？
API Key 无效或余额不足，请到服务商后台检查。

提示 HTTP 404？
模型名称或接口地址不对，在设置里点“获取模型列表”重新选择。

我的数据去了哪里？
见 隐私政策。

FAQ

Does it cost anything?
The app is free. AI features use your own API key from a provider such as OpenAI, Anthropic, Google, DeepSeek or OpenRouter, and the provider bills you for usage. Settings › Usage and Cost shows how many tokens you've used and what they cost.

Handwritten answers don't work?
Handwritten answers and image questions need a model that accepts images (for example Claude, GPT or Gemini). Text-only models can't read images.

HTTP 401 / 403?
The API key is invalid or out of credit. Check your provider's dashboard.

HTTP 404?
The model name or endpoint URL is wrong. In Settings, tap “Fetch Model List” and choose again.

Can the AI answer in English while the app is in Chinese (or the other way round)?
Yes. Settings › AI Response Language lets you choose Chinese or English independently of the interface.

Where does my data go?
See the Privacy Policy.
